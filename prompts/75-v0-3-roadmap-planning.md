Continue working on the cloudivision project.

Create the v0.3 roadmap.

4. Supply-chain security
- SBOM
- scanner
- signing
- provenance
- policy enforcement

5. Plugin/provider ecosystem
- plugin registry
- provider health
- config schema
- extension docs

6. Operational maturity
- observability dashboards
- alerts
- upgrade tests
- backup/restore
- scale test results

For each roadmap item include:
- problem
- user value
- proposed solution
- acceptance criteria
- risks
- dependencies
- whether it is must-have or nice-to-have

Acceptance criteria:
- docs/roadmap/v0.3.md exists.
- docs/roadmap/v0.3-backlog.md exists.
- Roadmap is realistic.
- v0.3 does not overload the product with unrelated features.
- v0.3 clearly builds on v0.2 results.
